One-line pitch

Before a wallet, lending market, index product, or agent trusts a tokenized stock, StockProof checks the issuer-to-mint identity and live Token-2022 state and returns a provenance-rich, machine-readable passport.

Problem and insight

Tokenized-equity interfaces often show a ticker and price while hiding the state that determines whether an asset is safe to consume. The ticker can resolve to a changed mint, the Scaled UI multiplier can change displayed balances after a corporate action, and transfers can be paused. A price feed cannot answer those questions. NFLXx is the concrete example: its effective onchain Scaled UI multiplier currently reads 10.0, so displaying a raw amount as a user balance can be wrong by a factor of ten.

Product and why Solana

StockProof pins 20 reviewed xStocks mints and reconciles each with official issuer metadata, proof-of-reserves reports, corporate-action records, and the live Solana Token-2022 mint account. The output is a versioned JSON passport with checks, exact evidence sources, RPC slot, capture time, and one of four states: PASS, CAUTION, BLOCKED, or UNVERIFIABLE. The Solana account is the verification boundary: without its extensions and pause state, the product cannot issue the same conclusion. It is read-only and does not execute trades.

User, distribution, and business hypothesis

The initial user is a developer integrating tokenized equities into a wallet, collateral system, index product, or autonomous agent. The first distribution wedge is the public passport API and JSON Schema: a developer can reject stale or non-PASS evidence before accepting a mint. A plausible future business is a managed monitoring/API tier with change alerts and coverage expansion. This is a hypothesis, not validated revenue or adoption. No third-party protocol integration, paying customer, or usage metric is claimed.

Current verification

On September 27, 2026, local checks passed: 68 automated tests, TypeScript/Vite production build, and a live Solami RPC mainnet scan of all 20 pinned assets. That scan returned 9 PASS and 11 CAUTION, with no BLOCKED or UNVERIFIABLE result. All 11 cautions came from the issuer's corporate-action schedule feed. A separate Solami WebSocket run established 20 mint subscriptions and observed advancing confirmed slots, but no mint state changes occurred during the short run. The public production API returned a live TSLAx passport sourced from rpc.solami.dev. These are point-in-time observations, not an uptime or future-verdict guarantee. 2–3 minute presentation script

Tokenized stocks are becoming composable, but most apps still treat a ticker and a price as enough. They are not. A wrong mint, a balance multiplier changed by a split, or a paused token can break a wallet or collateral system before a price chart notices.

StockProof is a preflight integrity layer. Pick a tokenized stock and it issues one inspectable passport: PASS, CAUTION, BLOCKED, or UNVERIFIABLE. The passport combines official xStocks records with the live Solana Token-2022 mint. It keeps the slot, source, capture time, and the exact checks that produced the verdict.

The insight is visible in NFLXx: its effective onchain Scaled UI multiplier is ten. An app displaying the raw amount as the user-visible balance can be wrong by ten times. We read the mint extension, select the effective multiplier by timestamp, and compare it with issuer metadata. If required evidence is missing, StockProof abstains. If identity or program checks fail, it blocks.

Our first users are developers who need to decide whether a tokenized equity is acceptable input for a wallet, lending market, index, or agent. The API and schema make the result usable by another application. We have not claimed external integration or revenue. The next step is to interview integrators, observe which checks they actually need, and expand coverage only where we can maintain a reviewed mint registry.

This is a working, read-only mainnet prototype, not a trading product and not an independent custody audit. Our aim is simple: make the invisible asset state visible before composability turns a bad assumption into a user loss.

Product-demo script (maximum 3 minutes)

  1. Open the production site and show LIVE · MAINNET. If it says snapshot or unverifiable, stop and recheck rather than recording a false live demo.
  2. Select NFLXx. Expand the multiplier check and show issuer and onchain values. Confirm the current live value before speaking; never narrate a cached result.
  3. Open mint evidence and follow the Explorer link. Point to the confirmed slot and source endpoint, then return to the app.
  4. Select one currently clean PASS asset and one currently CAUTION asset. Explain the actual check driving the difference without implying a failed corporate action.
  5. Download the passport JSON and show the internal Surface sample consumer stopping a stale or non-PASS result. State that Surface is an internal example, not a third-party adoption claim.
