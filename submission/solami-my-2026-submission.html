The user and problem

A wallet, lending-market, index, or agent developer integrating tokenized equities needs more than a ticker and a price. An issuer can change a mint, a Token-2022 Scaled UI multiplier can change displayed balances, transfers can be paused, and a corporate-action feed can contain stale records. These are integration failures, not price predictions.

What the product does

StockProof issues a versioned, evidence-backed passport for 20 reviewed xStocks on Solana. It reconciles official issuer data with the live Token-2022 mint and returns PASS, CAUTION, BLOCKED, or UNVERIFIABLE. The passport includes the Solana slot, capture time, source endpoint, and check-by-check evidence. Missing required evidence never becomes a clean PASS. The public UI and JSON API are working on mainnet.

Why Solami is the core data path

When configured for this deployment, every passport's required mint-account check uses Solami RPC exclusively. The route fails closed if Solami is unavailable instead of quietly returning a public-RPC passport. The public API exposes rpc.solami.dev as the chain evidence source without exposing the key.

The companion monitor calls Solami getMultipleAccounts for a confirmed snapshot of all 20 pinned mints, then holds one authenticated Solami WebSocket connection with 20 accountSubscribe filters plus slotSubscribe. On an actual mint-state change it compares the fields relevant to integrity—supply, Scaled UI multiplier schedule, pause flag, and freeze authority—and automatically reissues a full passport. This is an operational watch path, not a decorative provider logo or a single sample API call.

How judges can run it

Clone the public repository, run npm install, and place a standard read-only Solami key in the Git-ignored .env.local as SOLAMI_API_KEY=.... Run npm run solami:verify for authenticated passports and npm run solami:watch -- --duration=30 for the live account/slot watcher. The README documents setup, evidence, fail-closed behavior, and the difference between the Vercel API and the separate long-running watcher. No wallet or transaction signature is required.

What this does not claim

StockProof does not execute trades, independently audit offchain custody, or claim third-party integrations or paying users. Its proof-of-reserves ratio compares two issuer-reported numbers. The watcher is a runnable Node process, not an always-on hosted alert service. A short demo may show no account changes because mint parameters change infrequently.
